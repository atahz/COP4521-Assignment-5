About this project: This project uses Flask, Python, SQLite3, HTML, and
a crypography library to enhance our previous web app that had five pages: 
Home (to go to other pages), Add a New Baking Contest user (to add info 
and create a new user), List Baking Contest Users (to display user info 
for each user), List Contest Results (to display info about users'
baking items and votes received), and Results (to display messages).
We added a login page, specified the home page a user should see based
on their security level, and created a page for a user's contest results.
Moreover, we used Dr. Yuan's logic to encrypt and decrypt the fields
listed in the rubric.
Assumptions: Assumes that this is the only process running on port 5000.
Assumes that the name, phone number, and login password fields will have
appropriate values, although we implemented checks to ensure they are not
empty or do not only contain spaces. Assumes that the user is correctly
accessing the website's pages by clicking on the links, and not by modifying
the URL to access a page, although we implemented checks to ensure a user is
logged in and has the proper permissions to access certain pages.
