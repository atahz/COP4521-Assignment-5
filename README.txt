About this project: This project uses Flask, Python, SQL, and HTML to create a 
web app with five pages: Home (to go to other pages), Add a New Baking Contest 
user (to add info and create a new user), List Baking Contest Users (to display
user info for each user), List Contest Results (to display info about users'
baking items and votes received), and Results (to display messages).
Assumptions: Assumes that this is the only process running on port 5000.
Assumes that the name, phone number, and login password fields will have
appropriate values, although we implemented checks to ensure they are not
empty or do not only contain spaces.
